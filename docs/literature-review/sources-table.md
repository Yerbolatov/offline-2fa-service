## Вывод для проекта

Литература поддерживает двухуровневое решение. Для MVP следует реализовать RFC 6238 TOTP с секретом, зашифрованным отдельно от базы данных, атомарным запретом повторного кода, ограничением попыток и контролируемым окном времени.
Требования NIST SP 800-63B и OWASP ASVS превращаются в тестируемые требования к throttling, восстановлению, сессиям, RBAC, API и журналу аудита. WebAuthn следует оставить расширением: он сильнее против фишинга, но требует HTTPS, корректного origin и поддержки браузером/аутентификатором, что увеличивает операционную сложность автономной установки.
