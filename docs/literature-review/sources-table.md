## Conclusion for the Project

The literature supports a two-tier solution. For the MVP, RFC 6238 TOTP should be implemented with a secret encrypted separately from the database, an atomic code-reuse prohibition, an attempt limit, and a controlled time window.
The requirements of NIST SP 800-63B and OWASP ASVS are translated into testable requirements for throttling, recovery, sessions, RBAC, APIs, and audit logs. WebAuthn should remain an extension: it offers stronger protection against phishing but requires HTTPS, a valid origin, and support from the browser or authenticator, which increases the operational complexity of a standalone installation.
